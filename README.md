# Java Week 4 - File Handling Demo

This folder contains a simple Java example that demonstrates reading and writing text data using `FileWriter` and `FileReader`.

## Files

- `FileHandlingDemo.java` - Java source file showing how to write sample data, read it back, and append new data.
- `data.txt` - Text file containing the sample data used by the demo.

## How to run

1. Open a terminal in `java-week4`.
2. Compile the Java program:
   ```bash
   javac FileHandlingDemo.java
   ```
3. Run the demo:
   ```bash
   java FileHandlingDemo
   ```

## Notes

- The program writes initial data to `data.txt`.
- It reads the file contents and prints them.
- It then appends an additional item and prints the file contents again.
